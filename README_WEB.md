# Wizard Web Dashboard

Static Phase 3 dashboard for the Wizard research project.

## Local preview
Open `web/index.html` directly in a browser, or serve the repository root with any static HTTP server.

## Deployment
The `web/` directory is intentionally framework-free. It can be deployed to GitHub Pages, Vercel, Netlify, or any static host. The current signal cards are UI placeholders until a live API/data layer is connected.

## Safety
The dashboard does not claim live market data. Performance metrics should only be surfaced after the Phase 2 validation contract passes.
